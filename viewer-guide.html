03
装备怎么自动挂载？
告诉组件装什么装备，组件负责选择兼容的原生挂点。

      
你的配置逻辑槽 1 → 装备 503
→
装备元数据locator_launcher_
→
飞船 12032可用的发射器挂点

      
slot 是逻辑装备槽，不是原生挂点编号。例如，587 + 484 使用炮塔挂点，12032 + 503 使用发射器挂点。同一逻辑槽可能对应多个物理挂点；它们由船体资源定义，运行装配案例后，可用预览右上方的“挂点标记”查看位置，或展开预览下的实际结果。

      
支持 locator_turret_、locator_launcher_、locator_bomb_、locator_xl_ 和 locator_moonharvester_。按装备原生类型严格匹配，并检查容量及物理位置占用；没有兼容挂点时会报错。

      
这是模型展示装配，不校验 CPU、能量栅格或游戏内实际槽位限制。更换船体时，请同时提供适用的装备配置；fitting: { equipment: [] } 可清空装备。

    

    

      
04
HTML 属性
简单场景用属性配置，复杂场景使用 configure()。

      
属性默认值用途

        
item-id必填物品 ID，例如 587。
backgroundauto自动背景；none 关闭背景，也可指定背景资源的场景 ID。
control-panel关显示原版视觉设置控制区。
white-model关查看白模；保留已加载资源，支持随时切回。
effects开写成 effects="false" 可关闭特效。
auto-rotate关自动旋转模型。
antialiasautoauto / none / smaa / msaa2 / msaa4 / msaa8。
exposure0.7灯光亮度，范围 0.1–3。
reflection0.7反射强度，范围 0–3。
kill-count0击杀标记数量 0–999；需模型支持。
show-hardpoints关显示支持的装备挂点标记。
resource-base现有模型服务可选，自托管资源根地址，或本地同源代理地址。

      

      
control-panel、white-model、auto-rotate、show-hardpoints 以属性是否存在表示开关。关闭时移除属性；white-model="false" 仍然表示开启。

    

    

      
05
JavaScript API
configure() 返回 Promise。等待它完成后，再读取挂载结果或导出。

      
更新参数与查询装备
import './eve-model-viewer.js?v=fcc16a8bca1d0ed2';

const viewer = document.querySelector('eve-model-viewer');
await viewer.configure({
  itemId: 587,
  background: 'none',
  controlPanel: true,
  whiteModel: false,
  effects: true,
  render: { exposure: 0.7, reflection: 0.7, bloom: 0.2 },
  display: { antialiasMode: 'auto', occlusion: true },
  killCount: 0,
  fitting: { equipment: [{ slot: 1, itemId: 484 }] }
});

console.log(await viewer.getPlacements());
// 装配初始化后，查询指定逻辑槽当前可用的装备。
console.log(await viewer.getAvailableEquipment(2));
viewer.resetView();

      
configure() 合并顶层选项及 render / display 字段；传入 fitting 时，请给出完整的目标装备列表。render 还支持 sun / fill / f0 / roughness / dirt / depthOfField，display 还支持 bloom / depthOfField / textures。T3 子系统可用 subsystems: '1231' 指定组合，需对应资源可用。

      
导出模型与 HDR 天空盒
导出结果由宿主页面保存
function save(blob, name) {
  const url = URL.createObjectURL(blob);
  const link = document.createElement('a');
  link.href = url;
  link.download = name;
  link.click();
  setTimeout(() => URL.revokeObjectURL(url), 1000);
}

const model = await viewer.exportModel('glb'); // 也支持 'obj'
save(model.blob, 'ship-587.glb');

// 先选中并加载背景，再导出。
await viewer.configure({ background: 'auto' });
const skybox = await viewer.exportSkybox();
save(skybox.blob, skybox.name); // .hdr，保留 HDR 亮度范围

    

    

      
06
加载与事件
将组件接入自己项目的加载状态和错误提示。

      
事件监听
viewer.addEventListener('progress', ({ detail }) => {
  console.log(`阶段 ${detail.phase}/${detail.total}`);
});
viewer.addEventListener('load', ({ detail }) => {
  console.log('已加载', detail.itemId, detail.placements);
});
viewer.addEventListener('settings-change', ({ detail }) => {
  console.log('用户修改了控制区', detail);
});
viewer.addEventListener('error', ({ detail }) => {
  console.error(detail.message);
});

try {
  await viewer.configure({ itemId: 587 });
} catch (error) {
  if (error.name !== 'AbortError') console.error(error.message);
}

      
属性变更触发的错误通过 error 事件报告；显式调用 configure() 的错误通过 Promise 拒绝。事件监听请在首次加载前添加，之后也可通过 configure() 等待加载完成。

    

    

      
07
部署与常见问题
从本站示例到你自己的项目。

      
为什么在另一个域名下加载失败？
模型资源服务需要允许你的网页来源跨域读取（CORS）。本站仓库的 r2-cors.json 已提供公开资源 GET/HEAD 规则，但仍需应用到资源桶，并检查 CDN 缓存的响应头。若使用跨域 JS 地址，该 JS 服务也需要允许跨域模块导入。组件不携带登录凭据。

      
为什么标签没有显示，或只有很小的高度？
确认 JS 返回正确的 JavaScript 内容类型，页面通过 HTTP/HTTPS 打开，并为标签显式设置高度，例如 style="height:600px"。用浏览器控制台查看网络与加载错误。

      
React、Vue 或其他项目可以使用吗？
可以。先导入 JS，然后像普通自定义标签一样使用它。HTML 属性用短横线形式（如 item-id）；装备列表等对象通过元素引用调用 configure() 传入。无需再安装 Three.js。

      
一个页面能放多个模型吗？
可以，组件各自持有模型、设置和资源会话。多个复杂模型会增加 GPU 和内存开销；建议按需要插入，移除标签会释放对应场景，之后可以重新插入。

      
能和其他版本的 model-viewer 一起加载吗？
当前组件会注册 model-viewer 及其后处理标签，不支持同页再加载另一版本的 model-viewer 或本站旧 vendor bundle。只导入本组件即可。

      
组件里包含哪些控制区？
control-panel 显示原版视觉设置：背景、画质与性能、船体外观、光照与材质。装备由 API 配置；当前不包含图鉴、装备选择器或机库场景。
