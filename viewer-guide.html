01
引入组件
复制下面的 HTML 即可使用。


HTML
<!doctype html>
<html lang="zh-CN">
<meta charset="utf-8">
<meta name="viewport" content="width=device-width,initial-scale=1">
<title>EVE Model</title>
<script type="module">
  import 'https://eve.vanquisher.online/eve-model-viewer.js';
</script>
<eve-model-viewer
  item-id="587"
  background="none"
  style="width:100%;height:520px">
</eve-model-viewer>
</html>


模型和贴图由我们的资源服务加载，无需另外安装依赖。记得给标签设置高度。

03
装备挂载


equipment 传入装备 ID 数组。组件按顺序检查类型、空闲位置和容量，自动选择挂点。


配置[503,503]
→
装备挂点类型locator_launcher_
→
飞船 12032空闲的发射器挂点


587 + 484 演示炮塔，12032 + 503 演示发射器。空数组 [] 清空装备。某一项无法安装时会返回其位置和 ID，并保留原装配。






04
属性


属性默认值说明


item-id必填物品 ID，例如 587。
equipment[]装备 ID 数组，例如 [484,484]，按顺序自动挂载。


lang跟随页面en 或 zh-CN，设置组件语言。


backgroundautoauto 自动选择背景，none 不显示背景，也可传入场景 ID。


control-panel关显示原版视觉设置。


white-model关查看白模，可随时切回。


effects开effects="false" 关闭特效。


auto-rotate关自动旋转。


antialiasautoauto / none / smaa / msaa2 / msaa4 / msaa8


exposure0.7亮度，范围 0.1–3。


reflection0.7反射强度，范围 0–3。


kill-count0击杀标记数量，0–999；需模型支持。


show-hardpoints关显示装备挂点标记。




布尔属性以是否存在表示开关。关闭时移除属性，别写 white-model="false"。effects 除外，按上表传值。
