            01
            

              
Import

              
Copy this HTML to get started.

            

          

          

            

              HTML
              

                
              

            

            
<!doctype html>
<html lang="en">
<meta charset="utf-8">
<meta name="viewport" content="width=device-width,initial-scale=1">
<title>EVE Model</title>
<style>body { margin: 0; }</style>
<script type="module">
  import 'https://eve.vanquisher.online/eve-model-viewer.js';
</script>
<eve-model-viewer
  item-id="587"
  background="none">
</eve-model-viewer>
</html>

          

          

            Models and textures load from our asset service. No extra dependencies are needed. Width
            fills the parent by default; height follows the viewport (minimum 240px). Set a CSS
            height for an embedded area, or use height:100% inside a parent with a defined height.

            03
            
Equipment mounting

          

          

            Pass an array of item IDs in equipment. The component checks each item in
            order and assigns compatible free mounts.
          

          

            

              Configuration[503,503]
            

            →
            

              Equipment mount typelocator_launcher_
            

            →
            

              Ship 12032Free launcher mounts
            

          

          

            587 + 484 demonstrates turrets; 12032 + 503 demonstrates launchers. An empty array
            [] clears equipment. If an item cannot fit, its position and ID are
            reported and the previous fitting is retained.
          

        

        

          

            04
            
Attributes

          

          

            

              
                

                  Attribute
                  Default
                  Description
                

              
              
                

                  item-id
                  Required
                  Item ID, for example 587.
                

                

                  equipment
                  []
                  
                    Item ID array, for example [484,484], mounted automatically in
                    order.
                  
                

                

                  lang
                  Page language
                  
                    Set the component language to en or zh-CN.
                  
                

                

                  hangar
                  ""
                  
                    Hangar key, e.g. amarr; empty returns to space.
                  
                

                

                  subsystems
                  —
                  
                    Four-digit strategic cruiser subsystem configuration.
                  
                

                

                  background
                  auto
                  
                    auto selects a background; none hides it. A scene ID
                    is also accepted.
                  
                

                

                  control-panel
                  Off
                  
                    Show visual, fitting, subsystem and hangar controls.
                  
                

                

                  white-model
                  Off
                  
                    View the white model; switch back at any time.
                  
                

                

                  effects
                  On
                  
                    Use effects="false" to disable effects.
                  
                

                

                  auto-rotate
                  Off
                  Rotate automatically.
                

                

                  antialias
                  auto
                  auto / none / smaa / msaa2 / msaa4 / msaa8
                

                

                  power-preference
                  high-performance
                  default / low-power / high-performance. A browser hint; changing it reloads all viewers on this page.
                

                

                  exposure
                  0.7
                  Exposure, from 0.1 to 3.
                

                

                  reflection
                  0.7
                  Reflection strength, from 0 to 3.
                

                

                  kill-count
                  0
                  Kill marks, 0–999; requires model support.
                

                

                  show-hardpoints
                  Off
                  Show equipment hardpoint markers.
                

              
            

          

          

            Boolean attributes are enabled by their presence. Remove them to turn them off; do not
            use white-model="false". effects is the exception: use the
            value shown above.
