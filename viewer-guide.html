04
属性


属性默认值说明


item-id必填物品 ID，例如 587。


lang跟随页面en 或 zh-CN，设置组件语言。


backgroundautoauto 自动选择背景，none 不显示背景，也可传入场景 ID。


control-panel关显示原版视觉设置。


white-model关查看白模，可随时切回。


effects开effects="false" 关闭特效。


auto-rotate关自动旋转。


antialiasautoauto / none / smaa / msaa2 / msaa4 / msaa8


exposure0.7亮度，范围 0.1–3。


reflection0.7反射强度，范围 0–3。


kill-count0击杀标记数量，0–999；需模型支持。


show-hardpoints关显示装备挂点标记。




布尔属性以是否存在表示开关。关闭时移除属性，别写 white-model="false"。effects 除外，按上表传值。






05
JavaScript API
复杂参数通过 configure() 传入。等待 Promise 完成后再读取结果。


JavaScript
import 'https://eve.vanquisher.online/eve-model-viewer.js';

const viewer = document.querySelector('eve-model-viewer');
await viewer.configure({
  itemId: 587,
  background: 'none',
  controlPanel: true,
  render: { reflection: 0.7, exposure: 0.7 },
  fitting: { equipment: [{ slot: 1, itemId: 484 }] }
});

console.log(await viewer.getPlacements());
viewer.resetView();


configure() 会合并已有参数。传入 fitting 时给出完整装备列表；equipment: [] 清空装备。


方法 / 事件说明


getPlacements()查询实际挂载结果。


getAvailableEquipment(slot)装配初始化后，查询逻辑槽可用的装备。


exportModel('glb' | 'obj')返回含 Blob 的模型导出结果。


exportSkybox()背景加载后，返回 HDR 文件的 Blob 和名称。


progress / load / error加载进度、完成、错误事件，数据在 event.detail 中。


settings-change用户修改控制区时触发。




显式调用 configure() 时用 try / catch 处理错误。不要在同一页再加载其他版本的 model-viewer。
